# Simulatore politico

Gioco gratuito e open source: il giocatore guida il governo dell'Italia, con istituzioni e dati reali e personaggi e partiti inventati. Glossario in [`CONTEXT.md`](CONTEXT.md), ricerca in [`docs/ricerca/`](docs/ricerca/index.md).
